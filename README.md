# دهانات ديكورات ورق جدران بالرياض

موقع عربي متجاوب مبني باستخدام **Next.js App Router** لخدمة نشاط دهانات وديكورات وورق جدران في حي المصيف بمدينة الرياض.

## الخدمات

- دهانات داخلية
- دهانات خارجية وواجهات
- تركيب ورق جدران
- دهانات ديكورية
- معجون وتجهيز الجدران
- دهان فلل وشقق
- دهان مكاتب ومحلات
- تجديد وصيانة الدهانات

## التشغيل

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```

## Production

```env
NEXT_PUBLIC_SITE_URL=https://paint-decor-wallpaper-riyadh.vercel.app
```

المشروع مربوط بمستودع GitHub ويُنشر تلقائيًا على Vercel من الفرع `main`.
